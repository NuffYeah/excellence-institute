A Student Registration and Academic Management System for The Excellence Institute

This is a web application designed mainly to help administrators to register students, manage academic information, and securely store student data to a MySQL database.

The system also allows users (Students) to query the database for a student profile summary report and/or a registration confirmation slip using a unique student number. 

The app uses a PHP backend with MySQL database and a React+Vite frontend.
Apache and Node.js servers are used to host the app.
